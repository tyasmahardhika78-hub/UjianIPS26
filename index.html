Penyimpanan Permanen GitHub

Simpan soal langsung ke repositori GitHub agar tidak hilang saat refresh / pindah perangkat

2 Cara Agar Soal Tidak Terhapus di GitHub Pages:

1. Otomatis via GitHub API (Disarankan): Hubungkan repositori GitHub Anda di bawah ini. Setiap soal baru otomatis disimpan ke file soal-data.json di repositori Anda dan dimuat otomatis untuk semua siswa.

2. Tanpa Token (Statis): Klik tombol Ekspor index.html lalu unggah file index.html hasil unduhan tersebut ke GitHub. Semua soal sudah tertanam permanen di dalam kode HTML.

Token hanya disimpan di browser guru ini (tidak ikut diekspor ke siswa). Siswa tetap bisa membaca soal-data.json secara otomatis.
